# Apple Style Resume

Turn a Markdown resume and portrait into an Apple-inspired static website and A4 PDF, with restrained gray/white colors, rounded cards, clear hierarchy and the original **Inter / Noto Sans SC** typography.

## Install the skill with npx

Requires Node.js **22.20 or later** and npm. Installation uses the open-source [Vercel Skills CLI](https://github.com/vercel-labs/skills); this project does not need a separate npm package.

```bash
# Choose agents interactively; installs into the current project by default
npx skills add Cliccker/apple-style-resume

# Install for Codex in the current project without interactive selection
npx skills add Cliccker/apple-style-resume --skill apple-style-resume -a codex -y

# Install at user scope for use across projects
npx skills add Cliccker/apple-style-resume --skill apple-style-resume -a codex -g -y
```

Inspect skill discovery and installed skills:

```bash
npx skills add Cliccker/apple-style-resume --list
npx skills list -a codex
```

Codex is the verified target. You can select other supported agents in the installer; the Python scripts work the same way, but this project's skill invocation validation targets Codex.

## Typography: preserve the original appearance

**Typography is part of the design. Install [Inter](https://rsms.me/inter/) and [Noto Sans SC](https://fonts.google.com/specimen/Noto+Sans+SC)** for the intended appearance. Include weights 400, 500, 600 and 700; variable fonts are also suitable. Inter handles Latin text and Noto Sans SC handles Simplified Chinese. These are this template's choices, not Apple's official typefaces.

- Windows: extract the font files and install them using the context menu. macOS: use Font Book. Linux: place them in your user font directory and run `fc-cache -f`. Restart the browser or PDF export process afterward.
- By default, the template prefers the installed fonts and works offline. Font binaries are not bundled.
- If local installation is inconvenient, pass `--web-fonts` to load both families from Google Fonts. The previews use this option; viewing and exporting them requires access to Google Fonts.
- When the fonts are unavailable, system fallbacks can change glyph shapes, line wrapping and PDF pagination. Install the intended fonts before adjusting layout to compensate.

## Command-line quickstart

Requires **Python 3.10+**. HTML generation uses only the Python standard library. Run the following from a standalone checkout:

```bash
git clone https://github.com/Cliccker/apple-style-resume.git
cd apple-style-resume

# Chinese labels; body text stays in its source language
python scripts/md_to_resume.py examples/resume.zh-CN.md examples/avatar.png output/zh-CN --lang zh-CN

# English labels with optional online loading of the original fonts
python scripts/md_to_resume.py examples/resume.en.md examples/avatar.png output/en --lang en --web-fonts
```

Replace the input paths with your own files. The original three-positional-argument invocation is supported and defaults to Chinese. Quote paths containing spaces. `--lang` changes headings, the footer and HTML language; it does not translate the body.

| Output file | Purpose |
| --- | --- |
| `index.html` | Responsive static web resume |
| `resume_a4.html` | A4 print layout |
| `photo.jpg`, `photo.jpeg` or `photo.png` | Portrait copy preserving its extension |
| `resume.pdf` | Created by the export step below |

Open the HTML in a browser. Empty sections are hidden. Subsequent employers begin on a new PDF page, while long content flows naturally; there is no forced page count.

### Export PDF

```bash
python -m pip install -r requirements-pdf.txt
python -m playwright install chromium
python scripts/export_pdf.py output/zh-CN/resume_a4.html --output output/zh-CN/resume.pdf
python scripts/export_pdf.py output/en/resume_a4.html --output output/en/resume.pdf
```

On Linux, use `python -m playwright install --with-deps chromium` if browser system dependencies are missing. Alternatively, open `resume_a4.html` and print to PDF with A4 selected, background graphics enabled, browser headers/footers disabled and the template's CSS margins retained. Wait for fonts and the portrait to load, and inspect every exported page.

## Markdown input

See the complete [Chinese example](examples/resume.zh-CN.md), [English example](examples/resume.en.md) and [parsing guide](references/markdown-parsing.md).

- Use `# Name`, followed by the role, optional target role and contacts.
- Use H2 sections such as `Summary`, `Work Experience`, `Early Projects`, `Education` and `Gaming Experience`; corresponding Chinese headings are supported.
- Use `### Company | Role`, an italic date line, standalone bold project titles and achievement lists.
- Format education as `- **School** | Major | Degree | Year`.

This is a structured resume format rather than a general Markdown renderer. Arbitrary HTML, tables and complex inline formatting are not supported. Actual generated resumes retain the information you provide; generation does not automatically anonymize or upload them.

## Apple design references

| Official reference | Interpretation in this project |
| --- | --- |
| [Human Interface Guidelines — Typography](https://developer.apple.com/design/human-interface-guidelines/typography) | Organize content through type size, weight and hierarchy |
| [Human Interface Guidelines — Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | Use consistent alignment, whitespace and grouping |
| [Human Interface Guidelines — Color](https://developer.apple.com/design/human-interface-guidelines/color) | Use restrained colors to distinguish content and interaction |
| [Apple Mac website](https://www.apple.com/mac/) | Visual inspiration for simple typography, cards and generous whitespace |

Specific colors, font choices, corner radii and shadows are this project's decisions, documented in [DESIGN.md](DESIGN.md), not an Apple-prescribed resume standard. This independent project is not affiliated with Apple and includes no Apple logos, proprietary fonts or website screenshots.
